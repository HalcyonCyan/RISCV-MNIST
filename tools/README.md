# RARS

运行 `python scripts/setup.py` 会下载固定版本 RARS 1.6，并核对 SHA-256。

也可以将官方 `rars1_6.jar` 放到这里，重命名为 `rars.jar`。JAR 是运行工具，已加入 `.gitignore`，无需上传 Git。
